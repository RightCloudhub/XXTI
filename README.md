# XXTI

XXTI 是一个原创的多页面人格图鉴网站原型：保留 16 型的可读性，底层按四条连续维度计分。定位是「可玩的自我反思工具」，不是学术量表，也不是临床工具。

参考了 MBTI 的四轴 + 16 型表达、SBTI 的网页可玩性，以及 Big Five / HEXACO 的连续维度思路。

## 页面

- `index.html` 首页：四轴预览、三个入口、16 型速览、四维骨架、边界说明
- `wiki.html` 图鉴：16 型卡片 + 详情（优势、盲点、压力下、适配环境、升级建议、互补搭档），支持 `?type=QMBL` 直达
- `quiz.html` 测试：24 题，草稿自动保存；结果含类型、清晰度、四轴强度、互补搭档、分享链接（`?s=` 编码四轴分数）、本机历史与上次对比
- `method.html` 方法：设计依据、四维构成、计分方式、参考来源

## 目录结构

```text
index.html / wiki.html / quiz.html / method.html   页面模板，只写 <main> 里的内容
styles.css      全站样式：变量 → 基础 → 布局 → 组件 → 页面 → 响应式
js/data.js      内容：站点文案、四维、16 型、题库、量表
js/core.js      逻辑：计分、本地存储、分享链接（不碰 DOM）
js/dom.js       h() 建节点工具，文本一律走 textContent
js/layout.js    公共背景、导航、页脚
js/motion.js    GSAP 动效，缺少 GSAP 或开启减少动态时自动跳过
js/pages.js     各页面初始化，按 body[data-page] 分发
```

脚本都用 `defer` 按上面的顺序加载，共享一个全局命名空间 `window.XXTI`，所以直接双击打开 HTML 也能用。

只改文案、题目或类型资料时，编辑 `js/data.js` 就够了。

## 计分

- 每条轴 6 题，正反向各半
- 同意度 1 到 5 换算成 -2 到 +2，按题目方向累加，每轴分数在 -12 到 +12
- 正负决定字母，绝对值决定偏好强度；强度低于 15% 标为「接近均衡」
- 清晰度 = 四轴强度的平均值，只表示结果有多鲜明，不是准确率
- 互补搭档 = 四个字母全部取反

## 本地运行

纯静态站点，无需安装依赖。直接打开 `index.html`，或者在当前目录启动一个静态服务：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/
```

## 边界与限制

- 仅供自我观察和讨论，不用于筛选、诊断或定性
- 题库是原创网页题库，未做信效度检验
- 没有后端，草稿和历史只存在本机 localStorage
